## What this is
The starter is the template repo every new app starts from, Adam's or a client's: the stack, a design system, the prototype kit, the shared scripts, the skills and the agent definitions, already working, so a demo can be ready in a day. It holds no business features and no business screens (layer 1, the foundation). **This version is 0.1** (`SPEC.md`, specced 2026-11-04/06, two amendments from the spec chat on 2026-11-06; `TASKS.md`, chunks 0–10, planned 2026-11-06; the prototype in `prototype/` as the spec chat left it, plus the amendment's Offline sign-in state). Everything that already exists in Overload (`adamjuszczyk/overload-v2`, branch `staging`, commit `8e00877`) is lifted from it; only what Overload lacks is designed new. **It is not doing:** the client-ready build (staging and release scripts, maintenance mode, required updates, What's new, the iPhone install guide, forgot password, user roles, the environment setup script, user admin, audit log, exports, import, monitoring, backups), the offline writing add-on (the Dexie queue), Recharts, BUILD.md's client part, moving Overload or Current onto the starter, the installer demo itself.
